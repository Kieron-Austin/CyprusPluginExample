# Cyprus Plugin SDK

Make your own plugins for Cyprus Menu. PS4, ORBIS 1.750.

A PS4 inspired implementation of Scripthook 

## How to build

1) Make sure you have PS4 SDK 1.750 and visual studio installed 
2) Load project in VS 2012 and select Release/Orbis and then build
3) Once built go into the release folder and run post.bat this signs and gives the file the correct name.
4) Copy CyprusPluginExample.plugin to /data/Cyprus/plugins on your console
5) Load GTAV with Cyprus Menu and use Cyprus Menu to load CyprusPluginExample.plugin (in Misc submenu of the menu)

## Requirements
Cyprus Menu
PS4 SDK 1.750
Visual Studio 2012
Jailbroken PS4/PS5
